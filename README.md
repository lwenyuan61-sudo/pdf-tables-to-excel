# PDF to Excel

Free tool that turns the tables in a PDF into an Excel file (.xlsx) or CSV.

**Use it:** https://lwenyuan61-sudo.github.io/pdf-tables-to-excel/

- Works on normal PDFs and on scanned PDFs (built-in text recognition: English, Chinese, French, German, Spanish).
- Runs entirely in your browser. Your files are never uploaded anywhere.
- Keeps numbers as real numbers (thousands separators, currency, percentages, negatives in brackets), and keeps codes like `00123` as text.
- One sheet per page, or all pages in one sheet.

Built with [pdf.js](https://mozilla.github.io/pdf.js/), [SheetJS](https://sheetjs.com/) and [Tesseract.js](https://tesseract.projectnaptha.com/).
